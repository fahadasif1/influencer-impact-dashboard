How is impact measured?

What we can measure now (public data):

  • Reach delivered: total plays on each video (views). A play count, not unique people.
  • Engagement: (likes + comments + shares) ÷ views. Shows how many viewers reacted.
  • Spread: shares and saves. Shares push the message to new people; saves show intent to come back to it.
  • Delivery vs plan: videos posted versus videos reported by each influencer.
  • Growth: each refresh adds a snapshot, so a video page shows how views grow over time.

What we cannot measure from public data: unique reach, audience location, registrations, ticket scans or attendance. To link views to registrations, give each influencer their own sign-up link, QR code or promo code and count sign-ups per code.
